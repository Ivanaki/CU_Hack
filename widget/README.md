# «Честный тап» — виджет на рабочем столе iPhone

Один виджет. Один тап. Тап открывает диктовку наличных, а через секунду
показывает карточку месяца с процентом осознанности и — если система
чего‑то не поняла — с вопросом, который закрывается тем же одним тапом.

```
рабочий стол → тап → «кофе 300» → карточка: 125 918,20 ₽ · 99 % · 1 вопрос
                                  [Вернули долю] [Вернули долг] [Подарок] [Это доход]
```

Файлы:

| Файл | Что это |
|---|---|
| `SHORTCUT.md` | пошаговый рецепт быстрой команды |
| `icon.png` | значок для иконки на рабочем столе, 1024×1024 |
| `../app/api/quick.py` | три эндпоинта виджета |
| `../miniapp/dist/w.html` | страница карточки |
| `../tests/test_quick.py` | 17 тестов на маршруты |

## Почему виджет действует, а не показывает

Соблазн был сделать «Whoop для денег»: плитка на рабочем столе с большим
процентом осознанности. Против этого два довода, и первый технический.

**Виджет Shortcuts физически не умеет показывать живые данные.** Плитка
рисует только имя команды и её значок; чтобы вывести на рабочий стол
меняющееся число, нужно стороннее приложение‑виджет (Scriptable, Widgy)
или собственное приложение с WidgetKit. Первое — просить жюри поставить
чужую программу, второе — недельная работа и TestFlight. Плитка с
нарисованным «99 %», которое никогда не меняется, — это не демонстрация,
а декорация.

**И показывать было бы неправильно по продукту.** Обещание — 0–2 действия
в день, причём в тихий день ноль. Витрина, на которую человек ходит
смотреть каждый день, работает против собственной метрики: ежедневный
взгляд на дашборд — это и есть то, от чего трекеры бросают. Полезнее
сократить единственное, что инструмент действительно требует от человека.

А требует он ровно двух вещей, и обе попали в виджет:

1. **Наличные.** Единственное, чего нет ни в одной выписке и что без
   человека узнать неоткуда. Голос — самый короткий способ их внести.
2. **Ответ на спорную операцию.** Один тап по кнопке, которую система
   сама и предложила.

Всё остальное — выписки, скриншоты, категории — приезжает само и виджету
не нужно. Показ при этом никуда не делся: он приходит через секунду после
тапа, полноэкранным, с растущим кольцом. Просто он следствие действия, а
не приглашение к разглядыванию.

**Где виджет в общем сценарии.** Двойное касание по задней панели ловит
момент «я в приложении банка» — скриншот. Виджет ловит момент «я на
рабочем столе» — наличные и вопрос. Бот остаётся каналом, который приходит
сам. Три входа не пересекаются.

## Установка на iPhone (5 шагов)

1. Собрать команду `Честный тап` по `SHORTCUT.md` (3–4 минуты).
2. Запустить её один раз из приложения «Команды» и разрешить микрофон,
   распознавание речи и сетевой запрос.
3. Долгий тап по пустому месту рабочего стола → **+** в углу →
   **Быстрые команды** → виджет **2×2** → **Добавить виджет**.
4. Тап по виджету → **Изменить виджет** → **Быстрая команда** →
   `Честный тап`.
5. Проверить: тап по виджету, сказать «кофе 300», дождаться карточки.

**Вместо виджета — иконка.** Если хочется свой значок, а не стандартную
плитку: «Команды» → ⋯ на команде → **Поделиться** → **На экран «Домой»** →
выбрать `widget/icon.png` как картинку. Иконка неотличима от приложения и
на демонстрации смотрится ровно так же.

## Что показывать жюри

1. Рабочий стол iPhone. Тап по виджету.
2. «Такси 450». Карточка: сумма месяца выросла, кольцо осознанности,
   счётчик «действий в день».
3. На карточке — вопрос «Пришло 500 ₽ от Кати, что это?». Тап
   «Вернули долг». Кольцо тянется вверх, вопрос исчезает, появляется
   «Вопросов нет».
4. Фраза: «Это был один тап, и он записан в ту же таблицу, из которой
   считается число действий в день. Мы его не объявляем, мы его меряем».

## Как это подключается

Одна строка в `app/api/app.py`, рядом с `app.include_router(ingest)` и
**обязательно до** `app.mount("/", StaticFiles…)`:

```python
from app.api.quick import quick   # к остальным импортам
app.include_router(quick)         # рядом с include_router(ingest)
```

Статика Mini App примонтирована на корень и перехватывает всё, что
добавлено после неё: при неправильном порядке `/api/v1/quick/tap` молча
ответит `405 Method Not Allowed`.

Страница карточки (`miniapp/dist/w.html`) отдаётся той же статикой —
отдельного веб-сервера не появляется.

## Эндпоинты

Все три — в `app/api/quick.py`, префикс `/api/v1/quick`.

| Метод | Путь | Кто зовёт | Аутентификация |
|---|---|---|---|
| `POST` | `/tap` | быстрая команда | `X-API-Key` + `tg_id` в теле |
| `GET` | `/card` | страница карточки | токен `?t=` (или ключ + `tg_id`) |
| `POST` | `/answer` | кнопки на карточке | токен `?t=` (или ключ + `tg_id`) |

**Почему токен.** Служебный ключ пишет данные любому пользователю, и в
браузер его отдавать нельзя: адрес страницы уходит в историю, в скриншот
и в чужие руки. Поэтому `/tap` возвращает подписанный тем же ключом
пропуск, привязанный к одному `tg_id` и живущий полчаса. Состояния на
сервере он не требует — перезапуск контейнера посреди показа не гасит
открытую карточку.

Ответ `/tap` (сокращённо):

```json
{
  "ok": true,
  "headline": "Записал: кофе — 300 ₽",
  "period": "Сентябрь 2026",
  "spent": "125 918,20 ₽",
  "awareness": 99,
  "unclear": "1 700 ₽",
  "days_left": 11,
  "forecast": "к концу месяца ≈ 149 533,30 ₽",
  "open_questions": 1,
  "question": {"id": 5, "text": "…", "options": [{"code": "…", "label": "…"}]},
  "actions_per_day": 1.75,
  "notification": "Записал: кофе — 300 ₽ · Сентябрь 2026: … · осознанность 99 % · вопрос: 1",
  "card_url": "https://…/w.html?t=…"
}
```

Все денежные величины приходят строками, уже отформатированными:
Shortcuts не умеет расставлять разряды и знак рубля, а каждое
«собери строку» — лишнее действие в рецепте, который человек собирает
пальцем на телефоне.
